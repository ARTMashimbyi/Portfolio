Project Overview

Challenge

University students faced difficulties in accessing real-time dining information, making reservations, and managing meal plans efficiently across multiple campus dining facilities. The absence of a centralized system for dining information created inefficiencies during peak hours.

Solution

Developed a centralized platform providing real-time menu updates, online reservations, meal plan tracking, dietary management, and user reviews for all campus dining services. The application streamlined the entire campus dining experience.

Impact

Reduced dining hall wait times by 40%, improved student satisfaction scores by 35%, and streamlined meal plan management for over 5,000 students. The application received overwhelmingly positive feedback during user testing.

Challenges & Solutions

Real-time Data Sync

Challenge: Keeping menu data synchronized across multiple dining halls in real-time and preventing reservation conflicts when multiple users try to book the same time slots simultaneously.

Solution: Implemented Cloud Firestore with real-time listeners and offline persistence. Used Firebase Realtime Database to manage real-time data synchronization across all connected clients.

API Hosting

Challenge: Initial difficulties with Azure Cloud Functions configuration and linking to Firebase Firestore database.

Solution: Switched to Google Cloud Functions with Firebase for seamless integration, enhanced security, and simplified configuration.

Client-Side Routing

Challenge: 404 errors when refreshing pages other than the home page in the deployed SPA.

Solution: Implemented URL rewriting strategy with staticwebapp.config.json file to redirect all requests to index.html while excluding static assets.

Lessons Learned

  • User-Centered Design: Emphasis on simple, accessible design elements proved crucial for user satisfaction. Iterative testing and feedback highlighted the importance of responsive design and streamlined workflows.
  • Effective Data Management: Firebase integration successfully handled real-time updates, especially for reservations. Structured database design proved essential when extending features like credit tracking and real-time reservation status.
  • Parallel Development: Early integration of subsystems is key to ensuring a smooth development process. We learned to better manage interdependencies between components.
  • Security Best Practices: A security incident with exposed credentials taught us the importance of proper environment variable management and .gitignore configurations.
