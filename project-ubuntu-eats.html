Ubuntu Eats

Connecting Food Surplus with Community Needs

Hackathon Project Report | October 20, 2025

Executive Summary

Ubuntu Eats is an innovative food redistribution platform designed to combat food waste and address food insecurity. The application connects food donors (restaurants, supermarkets, individuals) with recipients (NGOs, charities, volunteers) to ensure surplus food reaches those in need rather than going to waste.

"Approximately one-third of all food produced worldwide goes to waste while millions face food insecurity. Ubuntu Eats addresses this paradox by creating a digital marketplace for surplus food redistribution."

User Role System

The platform supports four distinct user roles, each with tailored interfaces and capabilities:

Donors

Restaurants, supermarkets, and individuals with surplus food

  • Food listing creation
  • Image upload with drag-and-drop
  • Real-time status tracking
  • Chat with claimers

NGOs/Recipients

Charities and organizations serving communities in need

  • Browse available donations
  • Real-time claiming system
  • Filtering and search capabilities
  • Integrated chat with donors

Volunteers

Individuals helping with food transportation

  • Available delivery opportunities
  • Route planning assistance
  • Delivery status management
  • Navigation integration

Administrators

Platform oversight and management

  • Donation approval system
  • User management
  • Platform analytics
  • System monitoring

Challenges and Solutions

Technical Challenges

Real-time Chat Synchronization

Challenge: Ensuring consistent message delivery and ordering across multiple clients with optimistic updates.

Solution

Implemented sophisticated caching strategy with message deduplication and timestamp-based sorting.

Geolocation and Routing

Challenge: Providing accurate routing information when Google Directions API is unavailable.

Solution

Developed fallback route approximation algorithm with realistic road simulation.

Image Upload Performance

Challenge: Handling large image files efficiently on mobile devices.

Solution

Implemented client-side compression and progressive upload with preview generation.
